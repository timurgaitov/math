# Unit 2 — Proof techniques

Part of the [curriculum](../../curriculum.md). Method: [METHOD.md](../../METHOD.md).

## Goal

Own the standard proof shapes: direct, contrapositive, contradiction,
cases, and induction — knowing not just how each works but *when to reach
for which*, and what each obligates the writer to show. Raw material stays
elementary: integers, divisibility, parity, simple inequalities.

## Topics

- [x] Direct proof — name and formalize the skeleton already in use
      (arbitrary object → unpack assumptions via choose → compute →
      exhibit/verify the goal) — session 0003
- [x] Contrapositive: ¬Q ⇒ ¬P proves P ⇒ Q; when it's easier and why
      (e.g. "if n² is even then n is even") — session 0003
- [ ] Proof by contradiction; how it differs from contrapositive; the
      classic √2 ∉ ℚ
- [ ] Proof by cases; WLOG and its obligations
- [ ] Disproof: a counterexample is a proof (of the negation) — ties back
      to Unit 1 negation
- [ ] Induction: base case, inductive step, where the hypothesis gets used;
      strong induction
- [ ] Choosing a technique: reading a claim and picking the natural attack

## Done when

- Given a claim, student can name a sensible technique and say what the
  proof skeleton obligates them to show before doing any algebra.
- One correct proof written with each of: contrapositive, contradiction,
  induction.
- Student can articulate the difference between contrapositive and
  contradiction on a concrete example.
